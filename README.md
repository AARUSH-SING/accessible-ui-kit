# Accessible UI Kit

Accessible React Component Library
React, TypeScript, WCAG, WAI-ARIA, NVDA, axe-core

 Built WCAG-aligned reusable components with semantic HTML, keyboard navigation, focus management, accessible forms, dialogs, tabs, and menus.

 Tested with NVDA, keyboard-only navigation, and automated accessibility tooling, identifying and remediating accessibility violations.



## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
